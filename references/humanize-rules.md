# 去 AI 味规则

这份规则用于初稿后的复写，不是要求每篇稿件都故意加入俚语、口头禅或错别字。目标是：自然、清楚、能说出口，同时仍然像用户本人。

## 一、先判断“AI 味”来自哪里

逐段检查以下问题：

1. **空泛开场**：先谈时代、趋势、重要性，迟迟不进入具体主题。
2. **假装理解观众**：没有依据就说“相信很多人都有过这种经历”。
3. **结构过整齐**：每段相同长度，连续使用“首先、其次、最后”或三段式排比。
4. **抽象词堆叠**：充满“底层逻辑、赋能、价值、认知、维度、核心竞争力”，却没有动作或场景。
5. **书面连接词过多**：大量使用“然而、此外、因此、由此可见、综上所述”。
6. **句子一口气说不完**：从句太多、修饰过长，听众要回看才能理解。
7. **用力过猛**：每句话都是金句、反问或情绪最高点，没有轻重和呼吸。
8. **虚假背书**：凭空出现“我见过太多人”“粉丝一直问”“亲测有效”。

## 二、优先删除的套话

以下表达默认删除或改写，除非它们是引用、反讽，或确实属于用户稳定的个人口头禅：

- 在这个快节奏 / 信息爆炸 / 充满变化的时代
- 你是否曾经想过 / 你有没有发现
- 今天我们来聊聊 / 接下来我将为你
- 众所周知 / 不可否认 / 值得注意的是
- 其实答案很简单 / 真相只有一个
- 首先、其次、再次、最后
- 从某种意义上来说 / 在一定程度上
- 让我们一起 / 希望今天的分享对你有所帮助
- 综上所述 / 总而言之
- 这不仅仅是……更是……
- 真正厉害的人都懂得……
- 记住，永远不要……

不要只做同义词替换。若一句话没有信息，直接删除。

## 三、六种有效改法

### 1. 抽象判断改成具体场景

原句：

> 很多人在职业发展中缺乏清晰规划。

改写：

> 工作三四年以后，很多人会卡在一个地方：活越干越熟，下一步却不知道往哪走。

### 2. 宣讲口吻改成对话口吻

原句：

> 我们必须不断提升自己的核心竞争力。

改写：

> 你得想清楚一件事：同样的活，为什么下次还要找你？

### 3. 长句拆成有气口的短句

原句：

> 当你把所有精力都用在追求完美上时，就很容易因为害怕出错而迟迟无法开始行动。

改写：

> 你越想一次做到完美，越不敢开始。怕出错，结果就一直没动。

### 4. 空洞转折改成思路转折

原句：

> 然而，这并不意味着努力不重要。

改写：

> 但我不是说努力没用。问题是，你的力气花在哪。

### 5. 统一节奏改成长短交替

不要让每句都是十几个字的整齐排比。一个较长的解释后，可以用一句短话落地：

> 你以为自己缺的是方法，所以不停收藏课程、买工具、换计划。其实不是。你缺的是先做一版。

### 6. 假共情改成可验证观察

原句：

> 相信大家都经历过职场迷茫。

改写：

> 如果你最近一边想换工作，一边又说不清自己能换到哪，这条视频就是给你的。

## 四、保留“真人感”，但不要表演真人感

可以使用：

- “我更在意的是……”这类明确立场，但前提是用户确实提供了立场。
- “换句话说”“说白了”“问题在这”这类自然承接，少量即可。
- 短暂停顿、插入一句补充、轻微不对称的句式。
- 与受众相符的行业词，但第一次出现时让普通人也能听懂。

谨慎使用：

- 高频“说实话、讲真的、你知道吗”，容易成为新模板。
- 网络热词和方言，除非符合用户人设。
- 故意的病句、错字和夸张口癖。自然不等于粗糙。
- 每段都用反问。反问只在确实需要观众停一下时使用。

## 五、默读检查

最终交付前做一次无声或有声默读：

- 第一口气能否顺利说完第一句？
- 任一句是否包含三个以上逻辑转折？若是，拆句。
- 代词“这、它、他们”是否指向清楚？
- 删除一句后意思完全不变吗？若是，删掉。
- Hook 承诺的内容，正文是否真的回答了？
- 结尾是否在内容已经结束后又总结一遍？若是，砍掉总结。
- 金句是否像观点自然落地，而不是突然拔高？

最终稿允许口语，但必须准确。不要为了“像真人”降低事实可靠性。
