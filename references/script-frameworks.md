# 真人口播结构框架

框架用于选择，不用于堆叠。先看视频目标，再选择一个主框架；必要时只借用另一个框架的一小段。

## 一、先选择内容目标

| 内容目标 | 优先框架 | 常见场景 |
|---|---|---|
| 输出鲜明观点 | 结论—冲突—论证—落点 | 个人 IP、行业观察、职场观点 |
| 讲清一个知识 | 误区—解释—例子—应用 | 科普、财经、法律、技术 |
| 讲一个故事 | 异常瞬间—经过—转折—余味 | 人物、创业、成长经历 |
| 教会一个动作 | 结果预告—步骤—避坑—行动 | 教程、工具、方法 |
| 拆解热点 | 发生了什么—为什么重要—影响谁—我的判断 | 新闻、趋势、行业事件 |
| 建立共鸣 | 具体处境—隐藏感受—重新解释—小出口 | 成长、关系、情绪表达 |

## 二、六个主框架

### A. 观点型：结论—冲突—论证—落点

适合个人 IP 表达立场。

1. 直接给出一个可争辩的结论。
2. 点出多数人的默认看法，以及它遗漏了什么。
3. 用一个例子、对比或因果链支撑观点。
4. 把观点落回受众能使用的判断或动作。

避免：为了制造冲突而故意极端；只喊结论，不提供理由。

### B. 知识型：误区—机制—例子—应用

适合把复杂知识讲简单。

1. 指出一个具体误解，不泛称“很多人不知道”。
2. 用日常语言解释背后的机制。
3. 给一个足够小、能看懂的例子。
4. 告诉观众何时可以用上这条知识。

避免：塞入完整学科背景；使用术语后不解释。

### C. 故事型：异常瞬间—经过—转折—余味

适合真实经历或人物故事。

1. 从最有变化感的一刻切入，不从出生或背景讲起。
2. 只保留推动转折的两三个事件。
3. 让转折由选择或事实发生，不用“没想到命运弄人”代替。
4. 以一个画面、后果或克制的判断结束。

避免：编造细节；在故事末尾强行上价值。

### D. 教程型：结果—步骤—避坑—行动

适合技巧、工具和操作建议。

1. 先说观众最终能完成什么。
2. 只讲完成该结果所需的最少步骤。
3. 把最容易失败的一点放在相应步骤旁边。
4. 给一个可以立刻执行的小行动。

避免：口播里逐项朗读复杂菜单；一次教太多功能。

### E. 热点型：事实—意义—影响—判断

适合新闻与趋势，但必须先核实。

1. 用中性语言说明已确认发生的事。
2. 解释它为什么值得受众关心。
3. 区分已经发生的影响与可能发生的影响。
4. 给出有边界的判断，明确事实、观点与推测。

避免：用过时消息当最新事实；把推测写成确定结果；只复述新闻不提供增量。

### F. 共鸣型：处境—感受—重释—出口

适合成长与情绪类表达。

1. 写出一个可辨认的具体处境。
2. 说出观众可能难以命名的感受，但不要替所有人发言。
3. 提供一个不同的解释角度。
4. 给出很小、很现实的出口，不灌鸡汤。

避免：虚假共情；承诺“治愈一切”；把复杂问题归结为不够努力。

## 三、Hook 机制

3–5 个 Hook 应使用不同机制，而不是同一句换词。

### 直接结论

> 技术好，不代表你适合创业。很多时候，恰恰相反。

适合有明确观点的个人 IP。风险是结论过大，正文必须补足边界。

### 具体场景

> 你有没有这种一天：忙到晚上十点，关电脑时却说不清今天到底做成了什么？

适合共鸣与问题识别。场景必须和目标受众真实相关。

### 反常识

> 想把一条口播讲清楚，第一步不是写开头，而是删观点。

适合知识与教程。不能为了反常识说假话。

### 利益承诺

> 给我 30 秒，我帮你把一页讲不清的内容，压成三句话。

适合教程。承诺要在正文中被兑现。

### 悬念 / 信息差

> 这家公司销量涨了三倍，做对的却不是投更多广告。

适合案例与故事。尽快揭示关键事实，别拖到结尾骗完播。

### 身份点名

> 如果你工作三年了，工资没怎么涨，这件事比学新工具更重要。

适合窄受众内容。避免泛化成“所有人都应该”。

## 四、平台适配

只做轻量适配，不把平台刻板印象当硬规则。

- **抖音 / TikTok**：更快进入冲突或结果；一个视频解决一个问题；首屏句子短。
- **小红书**：具体经历、清单和“怎么做”更重要；避免装腔的成功学语气。
- **视频号**：可以多给一点上下文与判断依据；语气稳，避免只追求刺激。
- **B 站**：允许更完整的解释和例子；短口播仍要尽快说明问题与收益。
- **通用竖屏**：以清楚、自然、可剪辑为先，不强行添加平台热词。

## 五、按时长分配功能

### 15–30 秒

- Hook / 问题：15%–25%
- 核心解释或步骤：55%–70%
- 收束 / 行动：10%–20%

只保留一个例子或一个动作。通常不需要完整背景。

### 60–90 秒

- Hook：10%–15%
- 冲突与背景：15%–25%
- 论证、例子或步骤：45%–60%
- 收束：10%–15%

最多承载一个主观点和两个支撑点。

### 2–3 分钟

- 快速交代价值与主张。
- 用 2–3 个小段推进，每段都带具体例子或证据。
- 中段可轻微重置注意力，但不要重复 Hook。
- 结尾回到开头问题，给判断或下一步。

## 六、提纲检查

在写初稿前确认：

- 每一段是否有唯一功能？
- 删除背景后，观众是否仍能听懂？能就删。
- 例子是否证明主张，而不是只显得故事很多？
- 结尾是否给出了新价值，而非复述全文？
- 这个结构是否符合目标时长？
